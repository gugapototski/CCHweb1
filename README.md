Site institucional simples feito com HTML, CSS e JavaScript.

## Paginas

- `index.html`: pagina inicial.
- `produtos.html`: apresentacao de produtos.
- `trabalhe-conosco.html`: area de contato para candidatos.
- `orcamento.html`: solicitacao de orcamento.
- `pagina-extra.html`: conteudo complementar.

## Estrutura

```text
fotos/       imagens do site
style.css    estilos globais
script.js    interacoes simples
*.html       paginas estaticas
```

## Como visualizar

Abra o arquivo `index.html` no navegador.
